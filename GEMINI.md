# Diretrizes do Projeto

## Mensagens de Commit Git
- **Idioma Obrigatório**: Todas as mensagens de commit DEVEM ser escritas estritamente em **Português**, nunca em inglês.
- **Padrão**: Devem descrever sucinta e claramente a ação executada (ex: `Adiciona...`, `Atualiza...`, `Corrige...`, `Remove...`).
