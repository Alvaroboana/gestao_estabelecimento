# Regras para Mensagens de Commit Git

- **Idioma Obrigatório**: Todas as mensagens de commit DEVEM ser escritas estritamente em **Português**, nunca em inglês.
- **Estrutura**: Descrever de forma clara e objetiva o que foi adicionado, alterado ou corrigido.
- **Exemplos**:
  - `Adiciona modelos de domínio (Pessoa, Endereco, Contacto, Bairro)`
  - `Configura ambiente Docker e scripts de banco de dados SQL`
  - `Atualiza documentação e diagrama de classes`
  - `Corrige validação de contacto na camada de modelo`
